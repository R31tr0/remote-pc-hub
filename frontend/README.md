# 💻 Remote PC Hub — Frontend Client

> **Remote PC Hub** — веб-интерфейс для полноценного дистанционного управления файловой системой и мониторинга удаленной машины прямо из браузера.

## 🌟 Ключевые возможности

- 📂 **Полное управление файлами:** Навигация по файловой системе удалённого ПК, просмотр структуры папок, скачивание и работа с файлами прямо из интерфейса.
- ⚡ **Мгновенный отклик UI:** Оптимизированный глобальный стор на **Zustand** обеспечивает быструю работу приложения без лишних перерендеров.
- 🎭 **Плавные анимации:** Анимированный интерфейс, модальные окна и переходы между состояниями на базе **Framer Motion**.
- 🧭 **Удобный Routing:** Декомпозированная маршрутизация через **React Router DOM** (разделение экранов подключения, файлового менеджера и настроек).
- 📡 **Прямая интеграция с бэкендом:** Асинхронное взаимодействие с серверной частью через REST API / WebSockets.

---

## 🛠 Технологический стек

- **Core:** React 18, JavaScript (ES6+)
- **State Management:** Zustand
- **UI & Animations:** Framer Motion, CSS Modules / SCSS
- **Routing:** React Router DOM (v6)
- **HTTP Client:** Axios / Fetch API
